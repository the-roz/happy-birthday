# Best Friend Birthday Story

    npm install
    npm run dev

## Personalise
Edit **src/data/birthdayData.ts** (names, date, captions, memories, letter, file paths).

## Add your files (in `public/assets/`)
- her/her-01.jpg … her-08.jpg  (solo photos of her; her-01 is the portrait)
- us/us-01.jpg … us-04.jpg, us/us-final.jpg  (photos of both of you)
- video/our-story.mp4
- characters/bunny.png, fox.png, cat.png  (transparent PNGs of your own original characters)
- background-music.mp3

Anything missing shows a styled placeholder / emoji, so the site always runs.
